# Система Диалогов

Система диалогов в Avatar_Studio_QS позволяет создавать нелинейные разговоры с кинематографическим качеством.

## Основные компоненты

*   **Dialogue Asset**: Граф, где строится логика разговора.
*   **Voice Asset**: Хранилище аудио-файлов и текстов для конкретного персонажа.
*   **Lipsync Data**: Данные для лицевой анимации.

## Редактор Диалогов

Редактор открывается двойным кликом по ассету диалога.

### Типы Нод
*   **Start Node**: Точка входа.
*   **NPC Line**: Реплика персонажа.
*   **Player Line**: Вариант ответа игрока.
*   **Branch**: Условное ветвление (проверка квестов, переменных).
*   **Event**: Вызов событий (начать квест, выдать предмет).

## Озвучка и Липсинк

### Импорт Аудио
1.  Создайте **Voice Asset** для персонажа.
2.  Перетащите WAV файлы в панель "Voice Lines".
3.  Система автоматически создаст записи.

### Запекание Анимации (Baking)
Чтобы персонаж открывал рот, нужно запечь анимацию:
1.  В редакторе диалогов выберите ноду с репликой.
2.  Нажмите кнопку **Sync & Bake**.
3.  Плагин сгенерирует `AnimSequence` с кривыми для морфов и костей глаз.

> [!NOTE]
> Мы используем только вращение костей, чтобы сохранить пропорции вашего персонажа.

## Работа с Аудио и MFA (Advanced)

Плагин поддерживает продвинутые инструменты для работы с озвучкой, включая интеграцию с Montreal Forced Aligner (MFA).

### Импорт данных MFA
Если у вас есть JSON-файлы с разметкой фонем (например, от MFA), вы можете импортировать их для идеального липсинка.

**Формат JSON:**
Плагин ожидает структуру с массивами `words` и `phonemes` (см. пример ниже).

**Как импортировать:**
1.  Откройте **Voice Asset**.
2.  Нажмите кнопку **Import MFA Data** на панели инструментов.
3.  Выберите папку, где лежат ваши `.json` файлы.
    *   *Важно:* Имя файла должно совпадать с `LineID` реплики (например, `Intro_01.json` для реплики `Intro_01`).
4.  Плагин автоматически найдет соответствующие `LipsyncDataAsset` и заполнит их точными таймингами фонем.

### Экспорт для внешней обработки
Вы можете выгрузить аудио и текст из плагина для обработки в сторонних программах (например, для того же MFA).

1.  В **Voice Asset** выделите нужные реплики.
2.  Нажмите **Export Text/Audio**.
3.  Плагин создаст:
    *   `.txt` файлы с очищенным текстом реплик.
    *   `.wav` файлы (автоматически конвертируются в 16kHz Mono, что идеально для нейросетей).

## Экспорт Диалогов

Вы можете быстро создавать структуру диалога на основе списка реплик.

### Экспорт в Граф
1.  В **Voice Asset** выберите несколько реплик, которые должны идти друг за другом.
2.  Нажмите ПКМ -> **Export to Dialogue Graph**.
3.  Выберите целевой `DialogueAsset`.
4.  Система автоматически создаст цепочку нод в графе, заполнит текст и ссылки на аудио.

### Экспорт как Smart Node
Для сложных вариативных реплик (например, "Привет" с 5 разными интонациями):
1.  Выделите вариации одной фразы.
2.  Нажмите **Export as Smart Node**.
3.  В графе появится одна нода, которая будет случайно выбирать один из вариантов при запуске.
