# Avatar Studio QS

Добро пожаловать в документацию **Avatar Studio QS**!

Этот плагин представляет собой комплексное решение для создания RPG-систем в Unreal Engine 5. Он объединяет в себе инструменты для создания квестов, диалогов, управления NPC и фракциями в едином удобном интерфейсе.

## Установка

1.  **Копирование**: Поместите папку `Avatar_Studio_QS` в директорию `Plugins` вашего проекта.
2.  **Компиляция**: Запустите проект. Если появится запрос на пересборку модулей ("Missing modules"), нажмите **Yes**.
3.  **Проверка**: В редакторе перейдите в меню **Edit -> Plugins** и убедитесь, что плагин **Avatar Studio QS** включен.

## Начало работы

### Открытие главного окна

Весь функционал плагина сосредоточен в одном редакторе. Открыть его можно двумя способами:

1.  **Через меню**: В главном меню Unreal Engine перейдите в **Window -> Avatar Studio**.
2.  **Через панель инструментов**: Нажмите кнопку **Avatar Studio** на главной панели инструментов редактора (рядом с кнопкой Play).

### Обзор интерфейса

После открытия вы увидите главное окно плагина. Оно разделено на несколько ключевых зон:

[СКРИНШОТ: Главное окно плагина с цифрами-пометками зон]

1.  **Панель вкладок (Tabs)**: Верхняя строка с кнопками для навигации по разделам (Quests, Factions, Spawners, Dialogues, NPCs, Voices, Lipsync).
2.  **Локализация**: В правом верхнем углу находятся кнопки **EN / RU** для мгновенного переключения языка интерфейса плагина.
3.  **Панель инструментов (Toolbar)**: Находится внутри вкладки *Quests*, содержит кнопки для создания и загрузки системных файлов (Create System, Load System).
4.  **Рабочая область**: Центральная часть, содержимое которой меняется в зависимости от выбранной вкладки.
