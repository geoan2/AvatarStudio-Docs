# Система Взаимодействия

Позволяет игроку взаимодействовать с миром: открывать двери, подбирать предметы, начинать диалоги.

## Настройка Игрока

Добавьте компонент `AS_IS_PlayerInteractionComponent` к вашему Character Blueprint.
Этот компонент отвечает за:
*   Поиск интерактивных объектов (Raycast или Sphere Trace).
*   Отображение виджета подсказки ("Нажмите E").
*   Отправку событий ввода.

## Создание Интерактивного Объекта

1.  Создайте Actor.
2.  Добавьте интерфейс `AS_IS_InterInterface`.
3.  Реализуйте функцию `OnInteract`.

### Пример: Сундук
```cpp
void AMyChest::OnInteract_Implementation(AActor* Interactor)
{
    OpenLid();
    GiveLoot(Interactor);
}
```

## Сканер (Scanner)
Компонент `AS_IS_ScannerComponent` позволяет "подсвечивать" интерактивные объекты вокруг игрока.
Настройте радиус и типы объектов в деталях компонента.
