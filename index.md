# Начало работы с Avatar_Studio_QS

Добро пожаловать в документацию **Avatar_Studio_QS**!

Этот плагин предоставляет полный набор инструментов для создания RPG в Unreal Engine 5, включая системы диалогов, квестов и взаимодействия.

## Установка

1.  Скопируйте папку `Avatar_Studio_QS` в директорию `Plugins` вашего проекта.
2.  Запустите проект. Если появится запрос на пересборку модулей, нажмите **Yes**.
3.  В редакторе перейдите в **Edit -> Plugins** и убедитесь, что плагин включен.

## Быстрый старт

### 1. Создание NPC
1.  В Content Browser нажмите ПКМ -> **Avatar Studio** -> **NPC Asset**.
2.  Назовите его `NPC_Guide`.
3.  Откройте ассет и настройте имя и меш персонажа.

### 2. Ваш первый диалог
1.  ПКМ -> **Avatar Studio** -> **Dialogue Asset**.
2.  Откройте редактор диалогов.
3.  ПКМ в графе -> **Add Start Node**.
4.  ПКМ -> **Add NPC Line**. Соедините Start с этой нодой.
5.  В деталях ноды выберите вашего `NPC_Guide` и напишите текст: "Привет, путник!".
