# Вкладка 6: Голоса (Voices)

**Voice Assets** — это "банки озвучки", где хранятся все реплики персонажей. Это центральное хранилище для аудио, субтитров, лицевой анимации и метаданных.

Вместо того чтобы разбрасывать аудио-файлы по проекту, мы собираем их в Voice Assets и связываем с NPC и диалогами.

[СКРИНШОТ: Вкладка Voices с деревом ассетов и таблицей реплик]

---

## 1. Что такое Voice Asset?

Voice Asset — это контейнер для голосовых реплик одного или нескольких персонажей.

### Структура:
*   **Voice Lines** — Таблица реплик (каждая строка = одна фраза).
*   **Metadata** — Связь с NPC, тегами, диалогами.
*   **Lipsync Data** — Данные для лицевой анимации (автоматически генерируются).

### Примеры использования:
*   `VA_Guard_Common` — Обычные реплики стражников ("Стой!", "Проходи").
*   `VA_Guard_Combat` — Боевые крики стражников ("За короля!", "Умри!").
*   `VA_Merchant_Greetings` — Приветствия торговцев ("Добро пожаловать!", "Что желаете?").

---

## 2. Структура Voice Line (Реплика)

Каждая реплика в Voice Asset содержит:

### 📝 Основные данные:
*   **Line ID** — Уникальный идентификатор (GUID).
*   **Subtitle** — Текст реплики (для субтитров и липсинка).
*   **Sound Asset** — Ссылка на аудио-файл (`.wav`, `.ogg`).

### 🎭 Связь с NPC:
*   **Required NPC Data Table** — Таблица NPC, к которой относится реплика.
*   **Required NPC Row Names** — Массив ID NPC, которые могут произнести эту фразу.
    *   Одна реплика может быть использована несколькими NPC (например, "Привет!" для всех стражников).

### 🏷️ Теги и контекст:
*   **Gameplay Tags** — Теги для фильтрации и поиска (например, `Dialogue.Greeting`, `Combat.Taunt`).
*   **Context Tags** — Дополнительные теги для условий (например, `Mood.Angry`, `Location.Tavern`).

### 🎬 Лицевая анимация:
*   **Lipsync Data Source** — Ссылка на `LipsyncDataAsset` (автоматически создается).
*   **Emotion Blocks** — Временные отрезки с эмоциями (например, "Радость с 0.5 до 2.0 секунд").
*   **Blink Timeline** — Моргания (автоматически или вручную).
*   **Eye Gaze Timeline** — Направление взгляда.

## 3. Voice Line Links — 🔥 KILLER FEATURE

**Система связывания реплик** позволяет создавать цепочки разговоров прямо в Voice Assets.

### Типы связей:
*   **Is Followed By** — "Эта реплика продолжается следующей".
    *   *Пример*: "Привет!" → "Как дела?" → "Отлично!".
*   **Is Reply To** — "Эта реплика является ответом на предыдущую".
    *   *Пример*: "Как тебя зовут?" ← "Меня зовут Джон".

### Визуализация:
В редакторе Voice Assets связанные реплики отображаются как **призраки** (ghost rows):
*   Призрак **снизу** = "Is Followed By" (продолжение).
*   Призрак **сверху** = "Is Reply To" (ответ).

### Зачем это нужно?
*   **Контекст**: Видите всю цепочку разговора в одном месте.
*   **Экспорт в диалоги**: Выберите цепочку и экспортируйте её в Dialogue Graph одной кнопкой.
*   **Переиспользование**: Одна реплика может быть частью нескольких цепочек.

## 4. Интеграция с MFA (Montreal Forced Aligner)

Voice Assets автоматически генерируют данные для липсинка с помощью **MFA**.

### Workflow:
1.  Загрузите аудио-файл в реплику.
2.  Введите текст субтитров.
3.  Нажмите **"Generate Lipsync"** (или это произойдет автоматически).
4.  MFA анализирует аудио и создает:
    *   **Word Data** — Временные метки для каждого слова.
    *   **Phoneme Data** — Временные метки для каждой фонемы (звука).
    *   **Intensity** — Сила произношения (для редуцированных звуков).

### Результат:
Система автоматически создает `LipsyncDataAsset` и привязывает его к реплике. Вы можете:
*   Редактировать фонемы вручную (вкладка **Lipsync**).
*   Добавлять эмоции и взгляд.
*   Экспортировать в Animation Sequence.

---

## 5. Экспорт в Dialogue Graph

**Одна кнопка — готовый диалог.**

### Workflow:
1.  Во вкладке **Voices** выберите реплики (можно выбрать цепочку через Links).
2.  Нажмите **"Export to Dialogue Graph"**.
3.  Выберите целевой Dialogue Asset (или создайте новый).
4.  Система автоматически:
    *   Создаст узлы диалога для каждой реплики.
    *   Свяжет узлы в последовательность.
    *   Привяжет NPC, аудио и лицевую анимацию.
    *   Добавит узел "End" в конце.

### Преимущества:
*   **Скорость**: Создание диалога за секунды вместо минут.
*   **Централизация**: Вся озвучка в одном месте.
*   **Синхронизация**: Изменения в Voice Asset автоматически отражаются в диалогах (через Voice Link).

---

## 6. Организация Voice Assets

### Рекомендации:
*   **По персонажам**: Создайте отдельный Voice Asset для каждого главного персонажа.
    *   *Пример*: `VA_Gandalf`, `VA_Frodo`, `VA_Aragorn`.
*   **По категориям**: Для второстепенных NPC группируйте по типам.
    *   *Пример*: `VA_Guards_Common`, `VA_Merchants_All`, `VA_Peasants_Greetings`.
*   **По сценам**: Для катсцен создавайте отдельные Voice Assets.
    *   *Пример*: `VA_Cutscene_Chapter1_Opening`.

### Папки:
Используйте папки для организации:
*   `/Voices/MainCharacters`
*   `/Voices/NPCs/Guards`
*   `/Voices/NPCs/Merchants`
*   `/Voices/Cutscenes`

---

## 7. Интеграция с другими системами

### Диалоги:
*   Узлы диалога ссылаются на Voice Assets через **Voice Link**.
*   Изменения в Voice Asset (текст, аудио) автоматически синхронизируются.

### NPCs:
*   NPC Data Table хранит массив **Character Voice Banks**.
*   Система автоматически выбирает подходящую реплику из банков NPC.

### Lipsync:
*   Каждая реплика автоматически создает `LipsyncDataAsset`.
*   Вы можете редактировать липсинк во вкладке **Lipsync**.
