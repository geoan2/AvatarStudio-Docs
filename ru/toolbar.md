# Панель управления Квестовой Системой

Эта панель находится в верхней части вкладки **Quests** и предназначена для глобального управления базой данных квестов.

[СКРИНШОТ: Панель инструментов крупным планом]

## Основные функции

### 1. Create System (Создать Систему)
Эта кнопка создает новый глобальный ассет **Quest System Data Asset**.
*   **Зачем это нужно**: Это "база данных", в которой хранятся ссылки на все квесты, диалоги и NPC вашего проекта. Без неё система не будет работать.
*   **Когда нажимать**: Только один раз, в самом начале работы над новым проектом.

### 2. Load System (Загрузить Систему)
Позволяет выбрать активную Квестовую Систему.
*   **Как работает**: При нажатии открывается выпадающий список всех найденных ассетов `QuestSystem` в проекте.
*   **Изоляция**: Системы работают **независимо друг от друга**. В редакторе вы можете работать только с одной активной системой одновременно.
*   **Сценарии использования**:
    *   **Base Game vs DLC**: Вы можете создать одну систему для основной игры, а вторую — для дополнения (DLC). Это позволит держать данные раздельно и не запутаться.
    *   **Разные миры**: Если в вашей игре несколько совершенно разных миров с разными правилами и квестами, удобно разнести их по разным системам.
    *   **Командная работа**: Разные геймдизайнеры могут работать над своими системами, не мешая друг другу (меньше конфликтов при слиянии файлов).

### 3. Create Quest (Создать Квест)
Кнопка быстрого доступа для создания нового Квеста.
*   **Действие**: Открывает диалоговое окно создания нового ассета Квеста.
*   **Результат**: Новый квест автоматически добавляется в текущую Квестовую Систему и появляется в списке слева.
