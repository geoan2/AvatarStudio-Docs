# Система Квестов

Система квестов управляет миссиями, отслеживанием целей и наградами.

## Структура Квеста

Квест состоит из **Стадий (Stages)**. Каждая стадия может иметь несколько **Целей (Objectives)**.

### Создание Квеста
1.  Создайте **Quest Asset**.
2.  В графе квеста добавьте ноды **Stage**.
3.  Соедините их в логическую цепочку.

[СКРИНШОТ: Граф квеста с несколькими стадиями]

## Цели (Objectives)
Внутри стадии вы можете добавить цели:
*   **Kill**: Убить определенное количество врагов.
*   **Talk**: Поговорить с NPC.
*   **Collect**: Собрать предметы.
*   **Location**: Посетить точку.

## Интеграция с Диалогами
Вы можете проверять состояние квеста в диалогах:
1.  В диалоге добавьте ноду **Branch**.
2.  Выберите условие **Quest State**.
3.  Укажите квест и требуемую стадию.

Если квест на нужной стадии — диалог пойдет по ветке True.
